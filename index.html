e-Operasi

Teacher information web app · PPD Johor Bahru · Sep–Dec 2026 · Built solo

Overview

A web app that turns the ministry's teacher data into charts, summaries and searchable records for officers at PPD Johor Bahru.

Problem

Teacher data arrives as huge text files with over a hundred columns. To answer simple questions like "who retires in five years?", officers had to open the file in Excel and filter by hand.

Solution

  • Six pages, one for each question officers ask: overview, find a teacher, demographics, grade, subject and retirement.
  • Malay and English, dark mode and adjustable text size.
  • Admins can upload new data and preview the changes before they're applied.
  • Account approval, JWT login and an activity log, because the data includes personal details.

Result

About 8,700 teachers in 139 schools are now searchable in a few clicks. The Subject page flagged 993 teachers (11.2%) teaching outside their trained subject.

  • React
  • TypeScript
  • Recharts
  • C# .NET
  • PostgreSQL
  • Docker
  • Python

Year 1 Capacity Dashboard

Live dashboard · PPD Johor Bahru · Oct 2026 · Designed and built solo

Overview

A dashboard that shows the Year 1 capacity of every primary school in the district on one page.

Problem

Officers tracked almost 100 schools in one shared Google Sheet with about 27 columns. Finding the full schools meant scrolling and comparing numbers by hand.

Solution

  • Three plain statuses (over capacity, nearly full, has space), one colour each.
  • Refined over many rounds of feedback: removed repeated numbers and labelled every figure.
  • Reads the shared sheet directly, so changes show up within seconds.
  • Hosted on GitHub Pages so it opens on any phone or in meetings.

Result

32 of 98 schools over capacity for the 2027 intake (14,928 applications) now appear at the top of the list.

  • HTML
  • CSS
  • JavaScript
  • PapaParse
  • Google Sheets
  • GitHub Pages

Malaysia Car Popularity Dashboard

Final year project · UiTM Shah Alam · 2025–2026 · Grade A

Overview

A five-page Power BI dashboard that helps car buyers see what's popular, what a car costs to run, and whether they can afford it.

Problem

Malaysian car data is scattered across government portals, dealer websites and reports, mostly as static PDFs and tables.

Solution

  • Combined seven sources, including 4.6 million registration records, in a Python ETL pipeline.
  • Scraped used-car listings with Selenium and BeautifulSoup.
  • Affordability page with salary, loan period and interest rate inputs.
  • A Flask and SQLite app for live fuel price updates.

Result

Tested with 8 users on 8 real tasks. System Usability Scale score: 83.44 (Excellent).

  • Power BI
  • Python
  • pandas
  • Selenium
  • Flask
  • SQLite
