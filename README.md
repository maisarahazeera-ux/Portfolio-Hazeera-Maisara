# Hazeera Maisara | Portfolio

My personal portfolio website as a web developer and UI designer, hosted on GitHub Pages.

**Live site:** https://maisarahazeera-ux.github.io/Portfolio-Hazeera-Maisara/

## Sections

Home, About Me, Skills & Tools, Projects, Experience, Certificates & Awards, Contact.

## Features

- Responsive layout with breakpoints at 860px and 520px, plus a mobile menu
- Project galleries in a popup dialog with a swipeable image slider (keyboard arrows supported)
- Contact form that opens the visitor's email app with the message filled in (`mailto:`)
- Interactive lanyard ID card that can be pulled and released using pointer events, so it works with both mouse and touch
- Respects the user's "reduce motion" setting (`prefers-reduced-motion`)
- Footer year updates automatically

## Tech stack

HTML, CSS and vanilla JavaScript, with no frameworks. Hosted on GitHub Pages.

## My contribution

I designed and built this site myself. I used AI coding tools for parts of the code, and reviewed and tested all of it before use.
